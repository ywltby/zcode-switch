# Z·SWITCH v1.7.0-beta.3

修复 beta.2 中“部分额度查询未完成 · 套餐尚未初始化”的误报，建议 beta.2 用户更新。

## 修复内容

- 已有项目 Key 的接口字段 `usageScene` 可能返回 `-1` 等历史值。beta.2 错把创建 Key 时使用的值 `1` 当成复用条件，导致有无 Coding Plan 都可能被提前判定为缺 Key。本版按官方客户端的既有 Key 选择规则处理。
- 订阅是否有效仍由官方订阅接口确认；已有 Key 不等于已开通套餐，缺少 Key 也不能证明套餐未初始化。
- 调整确实无法取得查询凭据时的提示，不再直接要求用户启用套餐。
- 账号、登录代次、组织和项目隔离保持有效；只复用当前账号可访问项目中的指定名称 Key，不创建长期 Key，不回退历史密钥。

## 验证

新增失败用例先复现误报，再验证修复；覆盖个人/团队、BigModel/Z.ai，以及有无 Coding Plan 两种情况。49 项 Rust 测试、6 项 Node 测试、i18n 和浏览器界面回归通过。

11 份账号副本重测中，10 个完整成功，1 个遇到网络错误；所有结果均不再出现 `project_key_missing`。查询前后原账号、live 文件和副本未变化。官方界面数值对照及原生界面完整验收仍待完成，因此继续作为预发布。

## 下载

- Windows x64：`*_x64-setup.exe` 为安装包，`*_portable.exe` 为便携版。
- SHA-256 校验和见 `checksums-*.txt`。

安装包未签名，Windows 可能显示 SmartScreen 提示。
