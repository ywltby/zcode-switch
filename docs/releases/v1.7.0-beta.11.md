# Z·SWITCH v1.7.0-beta.11

- 账号行新增「查资格」，只查询该账号；查到可领时立即进入后台串行领取队列，定时扫描开关不影响手动查询入队。
- 自动领取需要人工验证时，阻止迟到的验证码回调继续提交；手动验证仍可正常完成。
- 阻止切换到明确过期的登录快照，避免先关闭 ZCode 或覆盖当前登录；可通过「添加」重新登录同一账号以更新快照。
- 新导出的加密备份保留每个账号的查询与领取设备标识；旧备份仍可导入，但其中未保存的标识无法从备份恢复。
- 切换账号时保留 ZCode 的本机设备标识和监控会话；原有账号的查询与领取标识保持不变。
- 保留 beta.10 的额度时间显示、渠道标签和列表滚动修复。

Windows 本机文件：`zcode-switch_1.7.0-beta.11_x64-setup.exe`、`zcode-switch_1.7.0-beta.11_portable.exe` 和 `checksums-Windows-v1.7.0-beta.11.txt`。

本机打包和离线验收已完成，详情见[验收记录](../testing/concurrent-refresh-claim-recovery.md#11-beta11-本机打包2026-10-28)。本次未上传或安装，未进行真实领取或真实 ZCode 热切换验收。
