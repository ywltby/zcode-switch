# Z·SWITCH v1.7.0-beta.11

## 领取

- 可领套餐同时覆盖结算预览（`billing/preview`）与官方客户端的营销活动下发（`marketing/touch`），按 `plan_id` 去重。此前只查结算预览，营销活动类套餐会一律显示为空
- 新增「当前登录」行：未保存进账号库的登录也能直接查资格与领取，只借用凭证与真实设备标识，不写入账号、配置或凭证文件
- 领取前不再依赖本地套餐列表：列表只提供显示名，能否领取由服务端判定
- 领取前按客户端启动语义上报一次活动资格激活，每个「登录 + 设备」只报一次
- 账号行新增「查资格」，只查询该账号；查到可领时立即进入后台串行领取队列，定时扫描开关不影响手动查询入队
- 自动领取需要人工验证时，阻止迟到的验证码回调继续提交；手动验证仍可正常完成

## 额度与切换

- 额度与资格共享最多 3 个应用层任务槽位，同一账号同一版本只查一次；批量资格刷新不再逐账号等待 5 秒
- 阻止切换到明确过期的登录快照，避免先关闭 ZCode 或覆盖当前登录；可通过「添加」重新登录同一账号以更新快照
- 切换账号时保留 ZCode 的本机设备标识和监控会话；原有账号的查询与领取标识保持不变
- 新导出的加密备份保留每个账号的查询与领取设备标识；旧备份仍可导入，但其中未保存的标识无法从备份恢复
- 保留 beta.10 的额度时间显示、渠道标签和列表滚动修复

## 本机验收

2026-11-02 实机验证：`ZCODE GLOBAL BUILD`（`zcode-v3-start-plan-1102`，GLM-5.3-Flash 3 亿 Token）在 4 个账号上领取成功，服务端返回 `ok: true` 与生效、到期时间；合并前的同一批账号在这个接口上全部返回空 `data`。

Windows 安装包：`zcode-switch_1.7.0-beta.11_x64-setup.exe`、`zcode-switch_1.7.0-beta.11_portable.exe` 和 `checksums-Windows-v1.7.0-beta.11.txt`。
