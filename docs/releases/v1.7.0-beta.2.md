# Z·SWITCH v1.7.0-beta.2

本次预发布集中修复多账号额度串用和重复套餐展示，优先支持 ZCode 3.16.x。

## 更新内容

- 额度查询固定到指定账号及其当前登录信息，历史账号密钥不再参与请求或失败回退。
- Coding Plan 按项目获取短期 Token，多个账号、团队项目的缓存和额度独立保存、分别展示。
- 修复套餐实例和计量窗口合并，避免同一额度重复显示，同时保留不同项目或有效期的权益。
- 更新登录、删除账号或切换期间，旧请求结果不会覆盖当前账号行；刷新失败会保留同一登录下的旧额度及更新时间。
- 明确显示部分查询失败、需要更新登录、套餐尚未初始化等状态。
- 包含此前对 ZCode 自定义数据目录的适配，修复更改数据目录后账号切换不生效的问题。

## 兼容与验证

已有账号快照和旧 `.zsb` 可继续读取，无需清理或批量迁移。缺少可复用项目 Key 时，请先在 ZCode 中完成对应套餐初始化。查询可为已有 Key 签发短期 Token，不会自动创建长期 Key、领取套餐或修改账号文件。

47 项 Rust 测试、6 项 Node 测试、双语文案检查和浏览器界面回归已通过。11 份真实账号副本的 CLI 检查中，3 个完整成功，7 个提示缺少项目 Key，1 个出现网络错误。官方 ZCode 界面数值对照及原生界面真实账号验收仍待完成；本版保留预发布标记。详细边界见[额度隔离验收记录](https://github.com/ywltby/zcode-switch/blob/v1.7.0-beta.2/docs/testing/quota-account-isolation.md)。
