# Z·SWITCH v1.7.0-beta.6

手动刷新或自动扫描查到可领取套餐后，立即进入后台领取队列，不再等整轮查询结束。查询最多 3 个并发，领取保持串行并沿用任务间隔，领取等待不会暂停其他账号的扫描。

## 使用变化

- 「自动领取」开关只控制每 10 分钟的定时扫描，开启后立即扫描一次。关闭时，手动刷新发现的可领套餐仍会自动入队，已有队列继续处理。
- 账号行显示「排队中」或「领取中」。领取过程中可以刷新资格、重试单个账号的查询和开关定时扫描。
- 同一账号版本和套餐去重；资格消失、账号删除或换登录后，撤销尚未开始的旧任务。
- 保留失败冷却及待确认保护；结果尚未确认时不会自动重新提交。超时后持续复查后端状态，回执丢失也能在结果确认后恢复队列。
- 保留 beta.5 的额度刷新、窄屏布局和额度文字随进度条背景变色的修复。
