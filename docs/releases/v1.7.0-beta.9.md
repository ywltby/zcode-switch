# Z·SWITCH v1.7.0-beta.9

- 修复 beta.8 将 Start Plan 的套餐开始时间误标为额度生效时间的问题。按每项权益的 `effective_at` 显示真实生效时间；没有此字段时显示未知，不用领取时间猜测。

- 保留 Coding Plan 有效期起止时间、待生效套餐、过期套餐过滤，以及滚动期间后台刷新修复。

Windows 本机文件：`zcode-switch_1.7.0-beta.9_x64-setup.exe`、`zcode-switch_1.7.0-beta.9_portable.exe` 和 `checksums-Windows-v1.7.0-beta.9.txt`。
