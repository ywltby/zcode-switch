# Z·SWITCH v1.7.0-beta.12

## 设备标识

- 账号行新增「重置设备标识」：营销活动按设备标识去重，服务端对一个 device id 投递过之后不再下发同一档活动。重置后为该账号换一个新 id，等效于手动删除 ZCode 的 `telemetry-state.json`，但不动客户端自身的设备身份
- CLI 新增 `reset-device --id <账号>`
- 重置会立刻作废该账号的额度与资格缓存，下一次查询按新设备拉取

## 代理

- 设置里的代理现在覆盖全部业务请求：领取预览与提交、营销活动查询、激活上报、验证码配置与额度查询都走配置的代理出口；OAuth 登录窗口维持原行为
- 实测同一出口环境下换设备标识无法恢复资格时，换代理节点出口后再重置设备标识即可
- 代理地址无效时自动退回直连，不会让领取悄悄失联
- CLI 与 GUI 共用同一份设置，无需重复配置

## 界面

- 「重置设备标识」放在账号行副标题行，不占行内图标位，窄窗口下「查额度」等按钮不再被挤出

## 本机验收

- 代理链路对照验证：代理指向无监听端口时额度查询报 `network_error`（`unavailable`），恢复后 `complete` 并正常返回套餐数据
- `cargo test --lib` 93 项、前端 100 项、i18n 259 键、`vite build` 全部通过

Windows 安装包：`zcode-switch_1.7.0-beta.12_x64-setup.exe`、`zcode-switch_1.7.0-beta.12_portable.exe` 和 `checksums-Windows-v1.7.0-beta.12.txt`。
