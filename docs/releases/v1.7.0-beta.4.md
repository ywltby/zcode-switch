# Z·SWITCH v1.7.0-beta.4

账号列表补齐登录渠道标识，方便直接区分国际站与国内站。

## 更新内容

- 每个账号的资料行固定显示渠道：蓝色 `z.ai · 国际`、琥珀色 `bigmodel.cn · 国内`；英文界面对应 Global / China。
- 重命名时仍保留渠道标识；无法识别的账号显示“渠道未知”。
- 资料行支持换行，长账号信息与最小 520px 窗口均可正常排版。
- 包含 beta.3 对“套餐尚未初始化”误报的修复。

## 验证与下载

6 项 Node 测试、215 项双语文案键检查、浏览器界面回归及 520px 窄窗口检查通过。Windows 安装包构建、内嵌版本和隔离 CLI 检查通过。

- Windows x64：`*_x64-setup.exe` 为安装包，`*_portable.exe` 为便携版。
- SHA-256 校验和见 `checksums-*.txt`。
- 额度实际接口的验收边界见[验收记录](https://github.com/ywltby/zcode-switch/blob/v1.7.0-beta.4/docs/testing/quota-account-isolation.md)。

安装包未签名，Windows 可能显示 SmartScreen 提示。
