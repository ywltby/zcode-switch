# Z·SWITCH v1.7.0-beta.16

> live 行「查询中」横幅不再在启动瞬间闪烁。

## 变更

- live 行的「查询中…」资格横幅延迟 1.2 秒展示：启动时的自动资格预览通常在一两秒内返回，之前每次启动都会先闪一条横幅再消失
- 查询超过阈值仍未返回才补一次渲染亮出横幅，慢查询与手动刷新的加载反馈保留；失败提示（带重试按钮）不受影响

- 前端 142 项、`vite build` 通过
- 以上为合成数据验证；真实上游查询未在本机验证

Windows 安装包：`zcode-switch_1.7.0-beta.16_x64-setup.exe`、`zcode-switch_1.7.0-beta.16_portable.exe`。
